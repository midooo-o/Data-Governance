# 📊 Data Governance

### Enterprise Data Governance & Data Quality Pipeline

Transforming raw, inconsistent data into clean, reliable, and business-ready data using Python, Sweetviz, Great Expectations, Machine Learning, and Power BI.

---

## 📖 Overview

This project demonstrates a complete data governance workflow for improving data quality and preparing data for analysis and machine learning.

The pipeline includes data profiling, cleaning, masking sensitive information, validating data quality, training a Decision Tree model, and building an interactive Power BI dashboard for visualization.

---

## ✨ Features

- 📊 Data Profiling using Sweetviz
- 🧹 Data Cleaning & Preprocessing
- 🔍 Missing Value Handling
- 🔄 Duplicate Detection & Removal
- 🔒 Sensitive Data Masking
- ✅ Data Validation using Great Expectations
- 🤖 Decision Tree Classification
- 📊 Interactive Power BI Dashboard
